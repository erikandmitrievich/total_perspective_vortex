* [[file:~/personal/projects/42/total_perspective_vortex/mybci.py][mybci.py]]

An entrypoint of the project.

** =parse_args(argv)=

Is called from =main()=. Main purpose is to parse the given =argv=.

Creates an object =parser= (from module =argparse=). Defines arguments with validation and constraints (relative to subject, run, and mode). Parses according to outlined parser configuration (=parser.parse_args(argv)=). Goes through another validation step: subject against =SUBJECTS=, and run by membership in a =BASE_GROUPS= entry — delegated to =runs_for=, whose =ValueError= is surfaced as a usage error. Stores the resolved group in =args.runs=. Returns parsed arguments.

** =main(argv)=

Calls =parse_args(argv)=. Parsed arguments branch program to 3 paths:

- =args.subject == None=

  Calls =run_full_sweep()=.

- =args.mode == "train"=

  Calls =train(args.subject, args.runs)=.

- =args.mode == "predict"=

  Calls =predict(args.subject, args.runs)=.

* [[file:~/personal/projects/42/total_perspective_vortex/src/csp.py][csp.py]]

Heart of project. A from scratch implementation of CSP dimensionality reduction algorithm.

** =MyCSP(BaseEstimator, TransformerMixin)=

A class, inherits from =BaseEstimator= and =TransformerMixin=.

*** =__init__(n_components, log)=

Initialises self attributes from given arguments.

*** =_covariance(X)=

Gets the number of channels (=n_channels=). Reshapes the 3D tensor from =(epochs, channels, time)= to a 2D matrix of shape =(channels, epochs * time)= through tensor transposition and flattening. This concatenates the time-series of all epochs. Calculates covariance matrix (see "Concatenation estimator" from [[file:csp.org][csp.org]]).

*** =fit(X, y)=

Validates =n_components= is even and =classes= count being exactly 2. Assigns =self.classes_=, and calculates covariance matrices for different classes (=S_0=, =S_1=). Calls =eigh(S_0, S_0 + S_1)= and obtains eigenvalues and eigenvectors: =eigvals=, =eigvecs= (see "Why =eigh= is the right solver" from [[file:csp.org][csp.org]]). Stores descendingly ordered eigenvalues and eigenvectors in =self.eigvals_= and =self.filters_= (=self.filters_= holds the eigenvectors as rows; see "Convention warning" from [[file:csp.org][csp.org]]). In parallel, stores pseudo-inverse of spatial filters in =self.patterns_= — what a topomap should display; nothing consumes it yet.

Summing up, it calculates filter matrix which will be used to reduce dimensionality of raw epoch data. It's the main function of CSP.

*** =transform(X)=

Verifies the model is fitted using =check_is_fitted(self)= (which ensures the required learned attributes exist). Selects the leftmost and rightmost filters, as they produce the most discriminative variance between the two classes. Projects the raw data onto these selected filters (resulting in =X_prj=). Calculates the =features= array of shape =(n_epochs, n_components)=, where each value essentially represents the energy (variance) of the filtered brain activity for one component of one epoch. Finally, if =self.log= is set to =True=, a log transformation is applied to the features to compress extreme spikes and create a normal (bell-curve) distribution, which is much easier for linear classifiers to process. Returns features.

* [[file:~/personal/projects/42/total_perspective_vortex/src/train.py][train.py]]

Where training happens.

** =FitConfig=

Stores default split and estimator parameters used for training and sweep.

- =n_components= is responsible for the number of filters to be applied.
- =test_size= for the holdout fraction and the validation fraction inside each cv split.
- =n_splits= for number of validation tests.
- =seed= is the seed used for reproducibility.

** =model_path(subject, runs)=

Uses global =MODELS_DIR= to construct a path to a fitted model. Used in writing and reading fitted models by =train(...)= and =predict(...)=.

** =make_pipeline(n_components)=

Just returns the =Pipeline= object. Exists for convenience.

** =fit_pipeline(X, y, fit)=

=idx= represent array of indices (of labels). =train_split(...)= performs split of indices based on given arguments into train and test.

- =test_size= for training and test ratio
- =stratify= for keeping the original class ratio
- =random_state= for random state

Then makes a pipeline along with cross-validation object (=cv=). =scores= then stores accuracy of each fold (for =cv=). And finally, fits the model with =fit(...)= and returns a classifier (=clf=), train indices (=train_idx=), sorted test indices (=test_idx=), and scores.

** =train(subject, runs, config, fit, *, verbose)=

Performs loading of preprocessed epochs and labels (=X=, =y=). Gets classifier, train and test indices, and scores from =fit_pipeline(...)=. Creates a model directory just in case and populates created model (through =joblib.dump(...)=) with necessary for predicting data. Then goes =if verbose= condition, necessary for sweep vs train and predict. Returns =scores.mean()=

* [[file:~/personal/projects/42/total_perspective_vortex/src/predict.py][predict.py]]

Where a persisted model meets its held-out partition.

** =score_stream(clf, X, y, test_idx, *, verbose)=

Enters a for loop of test indices. Measures start time, stores predicted class for =X[i]= to =preds=, measures end time, and stores time delta in =latencies= per chunk (implemented to comply subject's requirements of <2s latency per chunk). Prepares and compares predictions versus truths, calculates the mean. =if verbose= (for =predict= mode) prints subject's outlined CLI table. Returns accuracy.

** =predict(subject, runs, *, verbose)=

Gets a model path from =subject= and =runs= (and checks path existence). Loads the model to =d=. Loads =X=, =y= from dataset (reloads unders persisted from model config). Checks model loaded indices length matches dataset loaded truth length (prevents different epochs comparison). Runs =score_stream= and returns accuracy.

* [[file:~/personal/projects/42/total_perspective_vortex/src/experiments.py][experiments.py]]

Defines run groups. Imported by [[file:~/personal/projects/42/total_perspective_vortex/src/sweep.py][sweep.py]], [[file:~/personal/projects/42/total_perspective_vortex/mybci.py][mybci.py]] and [[file:~/personal/projects/42/total_perspective_vortex/visualise.py][visualise.py]].

** =BASE_GROUPS=

The four task groups, as =(runs, label)= pairs (see [[file:eegmmidb.org][eegmmidb.org]]). Each group is one task repeated three times, so T1 and T2 keep one meaning across all three runs, which is what allows concatenation. Labels are printed by the sweep.

** =EXPERIMENTS=

Defines experiments for =run_full_sweep()=. Just adds additional two experiments on top of base groups, each pairing an executed group with its imagined counterpart.

** =SUBJECTS=

Merely a range of subjects. Exists for coherence: both CLIs validate against it, =run_full_sweep()= iterates it.

** =runs_for(run)=

Expands =run= to =runs=: =3= -> =[3, 7, 11]=. One run is not a binary problem on its own, the group is the training unit. Called by [[file:~/personal/projects/42/total_perspective_vortex/mybci.py][mybci.py]] (=train=, =predict=) and [[file:~/personal/projects/42/total_perspective_vortex/visualise.py][visualise.py]].
